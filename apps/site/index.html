Last.fm Scrobbler

A native, cross-platform scrobbler for macOS, Windows, and Linux. No per-player plugins — it reads "now playing" straight from your OS's own media session, and keeps scrobbling in the background from your tray or menu bar.

View on GitHub Releases

Why not just another plugin?

Player-specific plugins only work with one player. This app instead reads directly from each OS's native media-session API — MPRIS2 on Linux, SMTC on Windows, MediaRemote on macOS — so it works with whatever you're already using to play music, with zero per-player integration.

What's built

  • Now Playing

    Live track/artist/album info pulled straight from the OS, with love and tag actions.

  • Scrobble history

    Recent scrobbles with real album art, plus love and tag actions on any past track.

  • Profile & friends

    Top artists and your Last.fm friends' activity, without leaving the app.

  • Runs in the background

    Lives in the tray/menu bar and keeps scrobbling after you close the window.

  • Bring your own key — or don't

    Use your own Last.fm API key via Preferences, or a key baked into the build.

  • Offline-safe

    Scrobbles queue locally and submit once Last.fm is reachable again.

  • Native notifications

    In-app toasts and OS-level notifications for scrobbles, updates, and errors.

  • In-app bug reports

    File a GitHub issue straight from the app — no GitHub account required.

Status

Every planned piece above is implemented and tested — all three platform adapters, the full scrobbling engine, and the desktop app itself. There are no tagged releases or downloads yet, so for now the only way to run it is from source — follow the repo to be notified when the first packaged build ships. See the architecture doc and architecture decision records for the full design and reasoning behind it.
