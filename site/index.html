Last.fm Scrobbler

A native, cross-platform scrobbler for macOS, Windows, and Linux. No per-player plugins — it reads "now playing" straight from your OS's own media session.

View on GitHub Read the wiki

Why not just another plugin?

Player-specific plugins only work with one player. This app instead reads directly from each OS's native media-session API — MPRIS2 on Linux, SMTC on Windows, MediaRemote on macOS — so it works with whatever you're already using to play music, with zero per-player integration.

What's in the repo

Package Responsibility
packages/core Scrobbling engine — rules, offline queue, Last.fm API client, auth, logging
packages/shared-types Shared types and the PlaybackSource interface
packages/adapter-linux MPRIS2 (D-Bus) playback source
packages/adapter-windows SMTC playback source
packages/adapter-macos MediaRemote playback source
apps/desktop Electron + React + MUI desktop app
services/bug-report-relay Anonymous bug-report → GitHub issue relay
